# Всё куплено — сайт

Этот репозиторий — новый лендинг вместо Тильды. Сайт простой: обычные HTML/CSS/JS файлы,
без сложных инструментов сборки, чтобы вы могли попросить Клод внести правки в любой момент.

## Структура файлов

- `index.html` — весь текст и структура страницы (секции: шапка, приветствие, «как это работает»,
  тарифы, вопросы-ответы, футер).
- `styles.css` — оформление (цвета, отступы, шрифты).
- `config.js` — **самое важное для правок**: ссылки на ботов (Telegram, MAX) и тарифы.
  Большинство обновлений — это правка именно этого файла.
- `script.js` — логика: подставляет ссылки и цены из `config.js` в страницу, обрабатывает
  нажатия на кнопки оплаты.
- `assets/img`, `assets/video` — папки для скриншотов и видео (добавим на следующих этапах).

## Как редактировать дальше

Вам не нужно самим писать код. Просто напишите Клоду в чате, что изменить
(«поменяй текст в шапке на …», «обнови цену тарифа Про на 990 ₽» и т.п.) — Клод внесёт
правки, закоммитит и запушит их в этот репозиторий.

## Дорожная карта

1. **Собрать контент** — перенести реальный текст/структуру с текущего лендинга (Клод не может
   открыть vsekupleno.ru напрямую — нужен ваш текст/скриншоты).
2. **Подключить ботов** — вписать ссылки на Telegram-бота и бота в MAX.
3. **Тарифы** — три тарифа с ценами и составом.
4. **Публикация сайта** — разместить на хостинге (рекомендуем Vercel: бесплатно, просто,
   поддерживает свой домен) и подключить домен vsekupleno.ru.
5. **Приём оплаты на сайте** — ЮKassa (оплата картой) и автосчёт, в дополнение к оплате в ботах.
6. **Скриншоты** — из бота и из онлайн-запросов цен, для наглядности.
7. **Видео** — короткий ролик о сервисе.
8. **Дальше** — любые правки и улучшения по мере необходимости.

## Локальный просмотр (по желанию)

Файлы статические, можно просто открыть `index.html` в браузере. Либо, если на вашем компьютере
установлен Python: `python3 -m http.server` в папке проекта и открыть `http://localhost:8000`.
